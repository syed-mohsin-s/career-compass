# **App Name**: Career Compass

## Core Features:

- Skill Profile Creation: Allow users to input their education, experience, and skills to create a detailed profile.
- Career Path Recommendations: Suggest 3-5 tailored career paths based on the user's skill profile.
- Skill Gap Analysis: Identify skills gaps by comparing the user's profile to the requirements of recommended career paths.
- Learning Resources Aggregation: Aggregate learning resources from platforms like Coursera and YouTube Edu to help users upskill, filtering the results with a tool based on keywords generated from the previous Skill Gap Analysis.
- Job Board Integration: Integrate with job boards like Google Cloud Datasets, LinkedIn, and Indeed to display relevant job postings.
- Resume Building Tool: A tool that guides the user through building their resume, providing AI-generated suggestions for bullet points and improvements based on their profile.
- Progress Tracking: Track user progress in skill development and job applications.

## Style Guidelines:

- Primary color: Sky blue (#87CEEB) to convey trust and aspiration.
- Background color: Light gray (#F0F8FF) to provide a clean and professional backdrop.
- Accent color: Soft orange (#FFB347) for key CTAs and highlights, adding warmth.
- Body text: 'PT Sans', a humanist sans-serif font for readability and a modern touch.
- Headline font: 'Space Grotesk', a modern, clean sans-serif font for titles and headers, and which can pair well with PT Sans for body text.
- Use a consistent set of minimalist icons to represent skills, career paths, and tools.
- Clean, card-based layout to organize information clearly and improve user experience.
